# Milestone v1.0 Handoff

## What was shipped

1. **Automatic draft PRs** — `execute-phase` creates a draft PR targeting `milestone/vX.Y` at start; idempotent via live `gh pr list` query; STATE.md PR column tracks `pr#N`
2. **Auto-promotion** — `verify-work` Route A promotes draft PR to ready-for-review via `gh pr ready`; STATE.md updated to `pr#N(ready)`
3. **AI PR reviewer** — `vit-pr-reviewer` agent spawns after promotion, posts severity-tiered body comment + up to 5 inline diff comments (`block-merge` / `should-fix` / `nit`)
4. **Per-phase doc updates** — `vit-doc-updater` spawns at execute-phase step 10.6 (after commit, before push) to update README/docs sections and append to `[Unreleased]` CHANGELOG
5. **Milestone changelog generation** — `vit-changelog-writer` spawns at complete-milestone step 3.5 (before archive) to promote `[Unreleased]` to `[VERSION] - DATE` and update all docs
6. **Zero manual GitHub operations** — every PR, review, doc update, and changelog entry triggers automatically through VIT workflow

## Key architectural decisions made

| Decision | Why |
|----------|-----|
| Idempotency via live `gh pr list` query | STATE.md can be stale after a context reset; GitHub is the authoritative source |
| doc-updater owns `[Unreleased]`, changelog-writer promotes it | Clean CHANGELOG ownership — no conflict between the two agents |
| Inline diff comments capped at 5 | GitHub API returns 422 on large diffs; block-merge findings prioritized first |
| All GitHub operations non-blocking (`|| log`) | `gh` unavailability or auth failures must never abort VIT workflow execution |
| Step 10.6 placed physically before 10.5 in execute-phase | Numerically after, but must run before push so doc commits are included in same push |

## Known tech debt

- `vit-changelog-writer` and `vit-doc-updater` are not registered as named subagent types; currently spawned as `general-purpose` with definition inlined. Once the agent registry supports custom types, update spawning calls.
- `complete-milestone` hardcodes `model="sonnet"` for changelog-writer; no model lookup table in that command. Low priority.
