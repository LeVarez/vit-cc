# Milestone v1.1 Handoff

## What was shipped

1. **Branded README** — ASCII art hero banner (ANSI Shadow in diff block for green rendering), 31-command reference across 11 groups, 16-agent table, model profile matrix, and 6 workflow recipes
2. **VitePress docs site** — 10 substantive content pages with blue-violet brand theming, Mermaid diagrams, and full sidebar navigation (Guide → Contributing → Reference)
3. **Contributor guides** — Command Anatomy and Agent Anatomy walkthroughs derived from source files, enabling self-service onboarding
4. **Reference pages** — GitHub Integration lifecycle, Configuration schema (11 config keys), Hooks & Sessions with pause/resume documentation
5. **GitHub Pages deployment** — `deploy-docs.yml` workflow verified with `actions/setup-node@v6`, ready to deploy on merge to main after enabling Pages in repo settings
6. **Audit gap closure** — All 6 audit gaps closed: install command, docs URL, model naming, cross-links, CI verification, Phase 02 VERIFICATION.md

## Key architectural decisions made

- **diff code block for README hero** — broadest GitHub compatibility for colored ASCII art (no HTML spans/font tags)
- **Isolated docs/ package.json** — decouples VitePress from root project, enables independent CI caching
- **base: '/vit-cc/'** — mandatory for GitHub Pages subdirectory hosting
- **Model matrix short form** — `opus`/`sonnet`/`haiku` (not `claude-opus`) matches source of truth in model-profiles.md
- **Cross-links in natural locations** — embedded in existing sentences, not forced "See also" blocks
