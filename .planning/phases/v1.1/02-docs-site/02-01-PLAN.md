2. Create `docs/.vitepress/config.ts`:
   - Use `withMermaid(defineConfig({...}))` pattern from vitepress-plugin-mermaid.
   - Set `title: 'VIT'`, `description: 'Phase-based project execution framework for Claude Code'`.

   - Add `themeConfig.search: { provider: 'local' }` (built-in, no external service).
   - Add `themeConfig.socialLinks` with GitHub link to `https://github.com/LeVarez/vit-cc`.
   - Add `themeConfig.editLink` with pattern `https://github.com/LeVarez/vit-cc/edit/main/docs/:path`.

3. Create `docs/.vitepress/theme/custom.css`:
   - Override `--vp-c-brand-1`, `--vp-c-brand-2`, `--vp-c-brand-3`, `--vp-c-brand-soft` with a blue-violet palette (e.g., `#7c6af5` primary, `#8f80f7` secondary, `#6a56e8` tertiary, `rgba(124, 106, 245, 0.14)` soft).

   - Import DefaultTheme from `vitepress/theme`.
   - Import `./custom.css`.
   - Export DefaultTheme.

   - Hero section: name "VIT", text "Phase-based execution for Claude Code", tagline "Every step reflected in GitHub. Zero manual operations."

<task type="auto">
  <name>Task 2: Create GitHub Actions deployment workflow</name>
  <files>
    .github/workflows/deploy-docs.yml
  </files>
  <action>
Create `.github/workflows/deploy-docs.yml` following the official VitePress GitHub Pages deployment pattern:

- Trigger on `push` to `main` branch and `workflow_dispatch`.
- Set permissions: `contents: read`, `pages: write`, `id-token: write`.
- Concurrency group `pages` with `cancel-in-progress: false`.
- Build job:
  - `actions/checkout@v5` with `fetch-depth: 0`
  - `actions/setup-node@v6` with `node-version: 20` and `cache: npm` with `cache-dependency-path: docs/package-lock.json`
  - `actions/configure-pages@v4`
  - `npm ci` with `working-directory: docs`
  - `npm run build` with `working-directory: docs`
  - `actions/upload-pages-artifact@v3` with `path: docs/.vitepress/dist`
- Deploy job:
  - Needs `build`
  - Environment `github-pages` with URL from deployment output
  - `actions/deploy-pages@v4`

Do NOT use `npm run docs:build` from root — use `npm run build` from `working-directory: docs` since docs has its own package.json.
  </action>
  <verify>
Validate YAML syntax: `python3 -c "import yaml; yaml.safe_load(open('.github/workflows/deploy-docs.yml'))"` must succeed. Verify the file contains `working-directory: docs` and `cache-dependency-path: docs/package-lock.json`.
  </verify>
  <done>deploy-docs.yml exists, is valid YAML, triggers on push to main, builds from docs/ directory, and deploys to GitHub Pages.</done>
